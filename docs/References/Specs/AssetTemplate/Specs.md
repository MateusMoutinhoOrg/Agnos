# AssetTemplate Specification

## Description
Defines the required shape of every file under `assets/` other than `asset.go` and `depsversion.yaml` — the Go `text/template`s `agnos build`, `start`, `dep-install` and `add-command` render into a project. Which group renders when is [BuildPipeline.md](/docs/References/BuildPipeline.md#asset-groups-in-order); adding one is [HandleAssetGroups.md](/docs/Tutorials/HandleAssetGroups.md).

### Rules
- A file in a group lives at `assets/<group>/<path>` and renders to `<path>` inside the project. The path is the whole addressing: nothing else names the destination. A single-file scaffold lives under `assets/templates/` and is rendered to a destination its action chooses.
- The file is valid Go `text/template` syntax and, once rendered with the variables of its group, valid content of its kind — parsable Go, valid YAML. `assets/` is never compiled, so this is checked by the follow-up build of the project it lands in.
- Import paths of the target module are `{{.Module}}/…`. This repository's own module path never appears.
- A template uses only the variables its renderer supplies: the full `vars` map for `all`, `deps` and `cli` (see [BuildPipeline.md](/docs/References/BuildPipeline.md#template-variables)); `Name`, `Version`, `Description` for `start`; `Module` alone for `deplist/<dep>`; `Module`, `Package`, `Identifier`, `Category`, `Help` for `command_*`; a command's collected map for `entries.go`.
- Loops iterate collected slices (`{{range .DepsLibs}}`); conditionals test the two switches (`{{if .HasDeps}}`). A template does no computation a collector could have precomputed.
- A generated Go file carries a comment saying it is generated by `agnos build` and must not be edited; a generated YAML carries the same as a `#` comment.
- The rendered output is deterministic for a given tree, so `agnos build` stays idempotent.

## Structure
1. **Header comment**: generated-by notice, for files a project might otherwise edit.
2. **Body**: the file as it should read in the project, with `{{.Module}}` for the module path, `{{range}}` over collected slices, `{{if}}` over the switches.

> **Note**: For a concrete example, refer to [sample.go](/docs/References/Specs/AssetTemplate/sample.go).
