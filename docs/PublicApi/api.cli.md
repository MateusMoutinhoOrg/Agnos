# `sandbox/api/cli.go`

| Constant | Value | Description |
| --- | --- | --- |
| `ExitOk` | `opinatedagnoscli.ExitOk` | ExitOk reports that the command did what it was asked to do. |
| `ExitFailure` | `opinatedagnoscli.ExitFailure` | ExitFailure reports that a well-formed command could not be carried out. |
| `ExitUsage` | `opinatedagnoscli.ExitUsage` | ExitUsage reports that the command line itself was wrong — an unknown command or flag, a missing operand, an unparsable amount. |

## `Cli`

Cli is the CLI surface of the sandbox: every command the project declares, and the dispatch that reads a command line against them. It is the OpinatedAgnosCli contract's Cli, built by sandbox/internal/generated/cli/cli/new.go, generated by `agnos build`.

`type Cli = opinatedagnoscli.Cli`
