# `sandbox/api/generated.cli.go`

| Constant | Value | Description |
| --- | --- | --- |
| `ExitOk` | `opinionatedagnoscli.ExitOk` | ExitOk reports that the command did what it was asked to do. |
| `ExitFailure` | `opinionatedagnoscli.ExitFailure` | ExitFailure reports that a well-formed command could not be carried out. |
| `ExitUsage` | `opinionatedagnoscli.ExitUsage` | ExitUsage reports that the command line itself was wrong — an unknown command or flag, a missing operand, an unparsable amount. |

## `Cli`

Cli is the CLI surface of the sandbox: every command the project declares, and the dispatch that reads a command line against them. It is the OpinionatedAgnosCli contract's Cli, built by sandbox/internal/cli/generated.new.go, generated by `agnos build`.

`type Cli = opinionatedagnoscli.Cli`
