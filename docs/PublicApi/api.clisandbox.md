# `sandbox/api/clisandbox.go`

## `CliSandbox`

CliSandbox is the cli layer's part of the Sandbox: api.Sandbox embeds it, so its field is read as sandbox.Cli. Generated by `agnos build` while sandbox-cli is on.

| Field | Type | Description |
| --- | --- | --- |
| `Cli` | `Cli` | Cli is the cli surface, built by the Constructor of sandbox/constructors/cli. |
