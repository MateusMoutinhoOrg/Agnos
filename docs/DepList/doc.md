# Installable Deps

## Description
Every dep `agnos dep-install <dep>` can render into a project — the sub-directories of `assets/deplist/`, which is what `agnos dep-list` prints. A dep is named after the **contract** it installs under `sandbox/deps/<dep>/`; it also carries that contract's adapter lib under `adapters/libs/<lib>/` and, for two of them, a pinned external module written into the project's `go.mod`. Installing and removing is [ManageDeps](/docs/ManageDeps/doc.md); adding a dep to this list is [HandleDeplist](/docs/HandleDeplist/doc.md); each contract is detailed under [PublicApi](/docs/PublicApi/doc.md#dependency-contracts).

## Deps

| Dep | Installs contract | Installs adapter lib | `Deps` field | External module | Provides |
|-----|-------------------|----------------------|--------------|-----------------|----------|
| `argvdeps` | `sandbox/deps/argvdeps/` | `adapters/libs/verb/` | `Argvdeps` | `github.com/MateusMoutinhoOrg/Verb` | An argument-vector parser created per call — [`argvdeps.Lib`](/docs/PublicApi/argvdeps.Lib/doc.md). The generated CLI dispatch reads the command line through it; `cli-init` installs it. |
| `dbdeps` | `sandbox/deps/dbdeps/` | `adapters/libs/keep/` | `Dbdeps` | `github.com/MateusMoutinhoOrg/Keep` | A schema database, the Keep library copied onto the sandbox. Not installed in Agnos itself. |
| `embeddeps` | `sandbox/deps/embeddeps/` | `adapters/libs/embeddeps/` + `assets/asset.go` | `Embeddeps` | — | Read-only access to files compiled into the binary, and Go `text/template` rendering of them — [`embeddeps.Lib`](/docs/PublicApi/embeddeps.Lib/doc.md). Also installs the `assets/` package holding the `//go:embed all:*` directive. |
| `goimportsdeps` | `sandbox/deps/goimportsdeps/` | `adapters/libs/goimportsdeps/` | `Goimportsdeps` | — | A Go source reader over `go/parser`: package clause, imports, top-level declarations — [`goimportsdeps.Lib`](/docs/PublicApi/goimportsdeps.Lib/doc.md). |
| `iodeps` | `sandbox/deps/iodeps/` | `adapters/libs/iodeps/` | `Iodeps` | — | The filesystem: read, write, existence checks, directory creation and removal, listings — [`iodeps.Lib`](/docs/PublicApi/iodeps.Lib/doc.md). |
| `requestdeps` | `sandbox/deps/requestdeps/` | `adapters/libs/requestdeps/` | `Requestdeps` | — | An HTTP request created per call over `net/http`, with a bounded round trip — [`requestdeps.Lib`](/docs/PublicApi/requestdeps.Lib/doc.md). |
| `rundeps` | `sandbox/deps/rundeps/` | `adapters/libs/rundeps/` | `Rundeps` | — | Running one external program to completion over `os/exec` — [`rundeps.Lib`](/docs/PublicApi/rundeps.Lib/doc.md). |
| `serializables` | `sandbox/deps/serializables/` | `adapters/libs/serializables/` | `Serializables` | — | Generic JSON/YAML values: create, parse, walk, serialize — [`serializables.Lib`](/docs/PublicApi/serializables.Lib/doc.md). |
| `std` | `sandbox/deps/std/` | `adapters/libs/std/` | `Std` | — | The process runtime: the clock, and the three output channels `Printf` / `Log` / `Error` plus `Errorf` — [`std.Lib`](/docs/PublicApi/std.Lib/doc.md). `cli-init` installs it. |

The `Deps` field is the title-cased contract directory, generated by `build`'s `CollectDepsLibs`; sandbox code reaches a capability by that name and no other. After `dep-install` of `argvdeps` or `dbdeps`, the `go mod tidy` that `build` runs downloads the pinned module.
