### Structure

create a automated doc,called structure, its a documentation that will show the description 
of the most important files and dir elements of the project.

### description of itens
all intens can be described, by creating a yaml file with its same path + specs.yaml
example: 

path: sandbox/binds 
specs: sandbox/binds.specs.yaml

### Important
all specs must be verified to not happen the risk of creating a "ghost spec"a spec of a file or a dir that were deleted.
### doc name

docs/structure/
