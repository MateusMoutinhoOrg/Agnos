# {{ .GeneratorName }}

Rendered by `{{ .GeneratorName }} build` ({{ .GeneratorName }} {{ .GeneratorVersion }}) from that binary's own commands: never
edit it, the next build rewrites it. `{{ .GeneratorName }} remove-skills` takes it away.

{{ .ProjectName }} is generated. Every `generated.<name>.go`{{ if .HasDoc }}, `docs/`{{ end }}{{ if .HasReadme }}, `README.md`{{ end }} and the wiring
between them are rendered from declarations: every change goes through a `{{ .GeneratorName }}` command,
never an edit of what it renders.

## The loop

```bash
{{ .GeneratorName }} <command> ...   # declares the change, then runs build for you
{{ .GeneratorName }} build           # verify + regenerate + go mod tidy + compile; a second run changes nothing
{{ .GeneratorName }} verify          # the schema check alone, writes nothing
```

Every command takes `--path <dir>` (default `.`) and `-q`. Run `build` after every hand edit; a
failed `verify` names the file and what to do.

## What you write

{{- if .HasCli }}

A command's `handler.go`, beside its `command.yaml`:

```go
func Handle(sandbox *api.Sandbox, props *commandprops.CommandProps, input *Input, response *api.CommandResponse) error
```

`input` holds every arg and flag of `command.yaml`, already typed and checked. `response.Printf`
answers (exit 0), `response.Logf` is progress, and
`return sandbox.Deps.OpinionatedAgnosCli.Fail(api.ExitFailure, "", err.Error())` refuses (exit 1).
{{- end }}
{{- if .HasServer }}

A route's `handler.go`, beside its `route.yaml`:

```go
func Handle(sandbox *api.Sandbox, props *routeprops.RouteProps, input *Input, response *serverdeps.Response) error
```

`response.SetStatus` or a `Write` answers; a handler doing neither declines, and the next route
of the chain runs. Refuse by returning `sandbox.Deps.OpinionatedAgnosServer.Fail`.
{{- end }}
{{- if .HasDatabase }}

A database's `methods_custom.go`: the one file of its package no build reads.
{{- end }}

`sandbox/` imports only `sandbox/` packages, the stdlib included: the outside world is
`sandbox.Deps.<Contract>`{{ if .HasDeps }}, and OS-bound or third-party code lives in `adapters/impls/`{{ end }}. Reusable logic goes in
`sandbox/internal/<pkg>/`, every function taking `sandbox *api.Sandbox` first.
