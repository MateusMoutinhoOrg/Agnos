## Build Architecture

## comands:
### agnos build

build the project
#### command:
~~~bash
 agnos build   
~~~

### agnos install
install some exetension in the project

#### command:
~~~bash
 agnos install  <item-to-install>  
~~~


### agnos uninstall
uninstall a extension in the project 

#### command:
~~~bash
 agnos uninstall  <item-to-uninstall>  
~~~
### agnos list
list all avaliables extensions 
#### command:
~~~bash
 agnos list 
~~~
### agnos extension-help 
show the help of a extension
#### command:
~~~bash
 agnos extension-help  <extension-name>  
~~~
