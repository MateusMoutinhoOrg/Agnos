## Objetivo:
Adicionar o comando compile no projeto.

## Comandos:

```bash
agnos compile --target linux86  linuxarm64  linuxi32 mac86 macarm64 windows86 windowsi32
```
para compilar todas arquiteturas de uma vez :
```bash
agnos compile --target all
```

## Importante:
- o comando compile tem que executar o build antes.
- edite a documentacao de desenvolvimento com essas novas modificacoes
